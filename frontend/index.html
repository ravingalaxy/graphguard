🧠 GraphGuard Architecture: Connected Data in Action

GraphGuard solves the cybersecurity alert fatigue problem using FalkorDB as the connected context engine for 4 specialized autonomous agents:

1. Enricher Agent

Executes 2-hop graph traversals across (INCIDENT)-[:AFFECTS]->(SYSTEM) and (INCIDENT)-[:AFFECTED]->(USER) to uncover blast radius in sub-10 milliseconds.

2. Threatographer Agent

Performs pattern matching on attack topology, MITRE ATT&CK techniques, and calculates graph centrality blast scores to attribute threat actors with high confidence.

3. Memory Agent

Persists stage transitions, inter-agent handoffs, and evidence cards directly into the FalkorDB graph, guaranteeing tenant isolation and auditability.

4. Orchestrator Agent

Synthesizes traceable Evidence Cards. Every finding is anchored directly to its Cypher traversal path, eliminating LLM hallucinations.

5. MCP Tool Selection & Autonomous Containment

Exposes graph queries and shortest-path algorithms as standard Model Context Protocol (MCP) tools for LLM agent selection, and executes real containment mutations in FalkorDB (host isolation, token revocation, firewall IP blocks).
